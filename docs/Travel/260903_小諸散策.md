# 旅の概要 ✨

墓威の家を拠点に、善光寺や小諸の街を巡る2泊3日。
圃場見学、温泉、焼き鳥、懐古園の散策を楽しみ、家ではギターやゲームで遊んだ。
帰りは軽井沢で解散し、上野へ。

## 感想・次回の注意点 💭

### 🌷 感想

- 善光寺には、一周回すと大量のお経を唱えたのと同じ効果が得られるというものがあった。どの時代にも効率を求める人はいるんだなと思った。TODO：名称と説明の詳細は未確認。
- やきとり結びは焼き鳥も酒もめちゃうまかった。お店のお姉さんも印象に残った。
- 懐古園はワインのイベントらしき催しで入場無料。ラッキー✌️ TODO：イベントの正式名称は未確認。
- 岸田酒店ではいろいろなジンを試飲できた。黒澤酒造とのつながりが深そう、という印象。
- 自分で珈琲を淹れてみたが難しく、不味くなってしまった。
- 帰りの新幹線は大宮まで座れず、きつかった。

### 📝 次回気を付けること

- 朝方に寒くて目が覚めたので、寝るときの寒さ対策。
- 帰りの新幹線で座れるよう、座席の確保を考えておく。
