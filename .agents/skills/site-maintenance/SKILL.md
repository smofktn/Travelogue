# MkDocs サイト保守

## この Skill を使う場面
- `README.md`、`mkdocs.yml`、GitHub Actions 関連ファイルを確認または編集するとき
- ドキュメント、テンプレート、サイト構成の整合性を見直すとき
- 低リスクなリポジトリ保守作業をするとき

## 手順
1. 編集前に関連ファイルを読みます。
2. 記載されたパス、コマンド、バージョンが実際のリポジトリと一致しているか比較します。
3. ずれや曖昧さをなくすための、最小限の変更を優先します。
4. workflow やセットアップ手順を変更する場合は、可能な範囲でローカル運用と CI の挙動を揃えます。
5. 検証コマンドを実行できない場合は、その理由を明確に伝えます。

## 主に確認するファイル
- `mkdocs.yml`
- `README.md`
- `.github/workflows/deploy-mkdocs.yml`
- `docs/` 配下の index / template ページ

## 最終確認
- ユーザーに案内するコマンドが、原則として実行可能な内容であること
- パス名とファイル名が実ファイルと正確に一致していること
- コメントが意図を説明しており、壊れやすい行番号参照に依存していないこと
