# 旅行記事更新

## この Skill を使う場面
- `docs/Travel/` に新しい旅行ページを作成するとき
- 既存の旅行メモを、ラフな記録から読みやすい形へ整えるとき
- 旅行ページをリポジトリのテンプレートに合わせるとき

## 入力
- 対象の旅行 Markdown ファイル
- ユーザーから渡されたメモや素材
- 必要に応じて、関連する画像や地図ファイルのパス

## 手順
1. `docs/Travel/travel-template.md` と対象ファイルを開きます。
2. 確認できた事実だけを残し、不明点を推測で埋めないでください。
3. ファイル名と Front Matter をリポジトリの慣例に合わせます。
4. 見出し、日付ブロック、金額欄、チェックリストは、元データが支える範囲でだけ整理します。
5. 画像や地図の参照があるのに実体がない場合は、ユーザーが追加する意図があるときだけ参照を残し、未作成であることが分かるようにします。
6. 編集後は、パスの大文字小文字、日付整合性、セクション順を軽く見直します。

## 出力
- 構造が整理され、事実面のリスクを抑えた旅行 Markdown

## 最終確認
- 案内文中のパスは `docs/Travel/` の表記になっていること
- Front Matter のキーが有効な YAML であること
- 推測で加えた事実が入っていないこと
