# Travelogue メモリ

## プロジェクト概要
- MkDocs Material で構成された静的ドキュメントサイトです。
- 主な目的は、旅行記録、博物館などの訪問記録、将来的な地図ベースの導線を蓄積することです。
- 現状は Markdown 中心で運用しており、自動化や高度なナビゲーションはまだ軽量です。

## 安定した運用ルール
- 旅行記事は `docs/Travel/` に置きます。
- 博物館などの記録は `docs/Museum/` に置きます。
- 旅行記事のファイル名は現在 `YYMMDD_旅行名.md` 形式です。
- セットアップ案内では `pip install -r requirements.txt` と `mkdocs serve` を優先します。

## 注意点
- パスの大文字小文字は重要です。`docs/travel/` ではなく `docs/Travel/` を使ってください。
- README、テンプレート、一覧ページは実ディレクトリ構成とずれやすいので、編集前に相互確認してください。
- 画像や GeoJSON の参照先は、ファイルが未作成でも先に書かれていることがあるため、存在を決め打ちしないでください。

## レビューで重視する点

- README と workflow の内容ずれ
- 公開ページとしてのナビゲーションの分かりやすさ
